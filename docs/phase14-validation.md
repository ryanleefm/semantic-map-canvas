# Phase 14：中央标题数学公式与英文换行

状态：Phase 14 已通过真实 Obsidian 用户验收，纳入正式版 0.1.0。

## 实现

- 普通节点的中央标题支持单行 $…$ 公式及文字混排，包括 shortLabel。沿用首个非空行和标题来源优先级；提取时保护公式中的下划线、星号和反斜杠。
- 使用 Obsidian 公共 loadMathJax / renderMath / finishRenderMath API，无新增依赖或网络请求。分组中央标题仍为纯文本。
- 标题内容变化才启动数学渲染；尺寸和字体变化只重新测量。异步完成后在既有扫描周期重新适配，无新增轮询。
- 公式作为不可断行的整体，按实际尺寸扩大排版盒后缩放，避免长公式偏离中心或溢出。
- 普通节点和分组均优先按英文单词换行。估算宽度考虑最长英文词（上限 1024 CSS px），超长字符串仍允许断行。保留中文自然换行、居中和自适应字号。
- 编辑、移除、切换画布及卸载会取消旧任务；失败保留源码。没有修改原始节点内容、语义层级、显示档位或元数据。

## 支持边界

采用保守行内识别：分隔符内侧不能有空白，不跨行，不将转义美元符号或 $$ 块级公式识别为行内公式；纯数字金额如 $25$ 保留原样。未闭合和不支持的语法保留可读文本。普通美元符号与数学符号存在语义歧义，需要字面美元时建议转义。

本阶段不提供完整 Markdown 排版，不渲染 group 名称中的公式。极长内容会缩得很小，完整容纳不保证缩到任意尺度仍可阅读。首次显示大量公式仍有 MathJax 排版开销；没有测定真实 Obsidian 的大规模公式帧率。独立弹出窗口的数学样式需要实际验收。

## 验收步骤

1. 在测试 vault 关闭再启用 Semantic Map Canvas，加载本次部署。
2. 打开 Semantic Map Canvas - Phase 14 - Titles.canvas。右键选择 L3 — Structure，检查英文句子、中文混排和长字符串；调整节点宽高并连续缩放。
3. 检查公式卡片：能量公式、下标、分式、多个公式和长公式。应显示数学排版并完整适应节点，公式内部不应被断开。
4. 检查金额、转义美元、未闭合公式、无效命令和 $$ 示例。异常内容至少保留可读文本，其他卡片仍正常。
5. 使用现有短标题设置入口，将任意普通节点的 shortLabel 改为含 $x_i$ 的文字，再清除，确认标题优先级和刷新。
6. 打开 Semantic Map Canvas - Phase 14 - Groups.canvas，选择 L2 — Overview，检查英文 group 名称优先按单词换行。
7. 在 Auto、L1–L4 间切换，再编辑标题、切换画布、切换浅深主题及卸载插件，确认原生显示恢复且无残留。
8. 如使用 Obsidian 独立弹出窗口，也在该窗口复查数学标题。
