# Phase 6 验证说明（0.0.5）

Phase 5、Phase 6 已由用户在真实 Obsidian 中验收通过。后续嵌套 group 改进见 [Phase 7–10 修改计划](phase7-10-plan.md)。

## 在 Obsidian 中验收

1. 在测试 vault 中关闭再启用 **Semantic Map Canvas**，加载 0.0.5。
2. 打开 **Semantic Map Canvas - Phase 6.canvas**。此画布包含普通标题、长标题、空标题和较小的 group，无需配置节点层级。
3. 从较大的缩放比例逐步缩小至低于 23%，进入 OVERVIEW：group 标题应移到内部中央，原生边缘标题隐藏，组内普通节点隐藏，边框与背景保留。
4. 在 OVERVIEW 中继续缩小：有足够空间时标题保持约 24px 屏幕字号；长标题换行，最多三行，空间不足时省略。较小区域降低至最低约 12px，极小区域会裁切，不能保证显示完整名称。
5. 放大超过 27%：居中标签移除，原生边缘标题恢复；超过 62% 时普通节点正文恢复。
6. 用原生方式修改 group 名称，再缩小检查中央标题同步。若原生标签处于编辑状态，应显示原生输入标签并暂停该 group 的中央标签。
7. 调整 group 大小、移动 group，确认标题随区域居中；插件本身不改变位置和尺寸。
8. 执行 **Semantic Map Canvas: Toggle semantic visibility**，确认立即恢复原生显示；再次执行恢复概览。
9. 切换 Canvas、切到普通笔记、禁用插件：原画布上的中央标签和辅助样式应清理，原生标签恢复。
10. 可继续打开 Phase 5 测试画布，确认节点层级、连线显隐与编辑行为无回归。

初次分类按 25% / 60%；之后缩小跨 23%、58%，放大跨 27%、62% 时切换。空 group 名称显示 Untitled group，不会写回画布。

## 已执行验证

- 44 项自动化测试通过，包括此前存储、菜单、显隐回归，以及 group 的字号计算、标题编辑、尺寸变化、DOM 替换、暂停、卸载和异常恢复。
- TypeScript / production build 与 ESLint 通过。
- 隔离的 Chrome headless 页面使用实际 GroupOverviewRenderer 和 styles.css，在 25%、12.5%、6.25% 下验证：1600 × 1000 group 的屏幕字号保持 24px，标题居中且在边界内；原生标题隐藏，进入 contenteditable 时立即恢复。截图人工检查通过。
- 浏览器测试使用模拟的 Canvas 外壳，不能替代真实 Obsidian、主题及其他插件的兼容性验收。

## 实现边界

仅处理活动 Canvas。缩放每 100ms 采样，已有标签只更新自身的 CSS 变量，不重新构建 DOM；标题及尺寸等变化沿用约 300ms 的扫描。快速连续缩放时可能短暂滞后。

中央标题使用原生 group 的 label 作为纯文本。插件保留原生 label 元素和内容，只添加可撤销的类；背景图、颜色、几何数据和 undo 历史不变。本阶段不包含节点默认尺寸预设。
