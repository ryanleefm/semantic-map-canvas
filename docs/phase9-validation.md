# Phase 9 验证说明（0.0.8）

状态：Phase 1–9 已由用户在真实 Obsidian 中验收通过。本说明保留 Phase 9 交付范围，整体收尾见 Phase 10。

## 四档缩放

| 边界 | 首次打开时 | 运行中缩小时 | 运行中放大时 |
| --- | --- | --- | --- |
| MAP / OVERVIEW | 10% 及以下为 MAP | 9% 及以下进入 MAP | 11% 及以上离开 MAP |
| OVERVIEW / STRUCTURE | 25% 及以下为 OVERVIEW（高于 10%） | 23% 及以下进入 OVERVIEW | 27% 及以上进入 STRUCTURE |
| STRUCTURE / DETAIL | 高于 60% 为 DETAIL | 58% 及以下进入 STRUCTURE | 62% 及以上进入 DETAIL |

支持一次缩放跨越多个档位，不必经过中间档位逐次刷新。切换到另一张画布时按首次打开规则重新分类。9%–11% 内维持已有档位，避免边界反复切换。

MAP 中普通 L1 显示简短标签；L1 group 可显示中央标题；L2–L4 隐藏。嵌套协调不变：内层仍有 L1 对象或正在编辑的对象时，外层 L1 group 保留边缘标题。正在编辑的低优先级对象临时保留，编辑结束后恢复显隐规则。未识别类型仍保守显示。

## 在 Obsidian 中验收

1. 关闭再启用 **Semantic Map Canvas**，加载 0.0.8。
2. 打开 **Semantic Map Canvas - Phase 9.canvas**，放大到 DETAIL。
3. **将两个最外层 group“知识领域”“项目领域”分别设为 L1 Domain。** 其余 group 保持默认 L2，普通节点保持默认 L3。本画布没有预写层级记录。
4. 缩小到 STRUCTURE：普通节点显示简短标签。
5. 缩小到 OVERVIEW（例如 15%–20%）：内部主题 group 显示中央标题，两个外层领域保留边缘标题。
6. 继续缩小至 9% 以下：进入 MAP，内部主题 group 和普通节点隐藏，只保留两个外层领域的中央标题。
7. 放大超过 11%：恢复内部主题 group；超过 27% 恢复普通节点简短标签；超过 62% 恢复原生完整内容和标题。
8. 在 9%–11% 之间反复小幅缩放，观察不会来回闪动。可在 Console 勾选 Verbose 并过滤 Semantic Map Canvas，查看 OVERVIEW → MAP / MAP → OVERVIEW 日志；也可执行 Log active canvas diagnostics。
9. 快速从 DETAIL 缩小到 MAP，再直接放大回 DETAIL，确认节点、group、连线和标题正确恢复。
10. 将“研究”内层 group 临时设为 L1：MAP 中它显示中央标题，“知识领域”保留边缘标题；恢复 L2 后回到外层中央标题。
11. 将一个普通节点设为 L1：MAP 中它仍显示简短标签，其包含区域保留边缘标题。编辑普通节点或 group 名称时检查编辑保护与退出后的恢复。
12. 将两个外层暂时恢复 L2，确认其他对象也没有 L1：MAP 中会没有语义对象显示。放大或执行 **Toggle semantic visibility** 即可恢复；不会删除内容或自动提升层级。
13. 暂停、切换笔记/Canvas、禁用插件后，原生内容应恢复。检查连接隐藏 group 的线条、箭头和标签同步隐藏，放大后恢复。

只有手动设置 L1 才会形成全局主题；group 默认值仍为 L2，节点默认值仍为 L3。较小区域的标题会换行、省略或裁切，沿用 Phase 6 的屏幕字号补偿。

## 数据与边界

继续使用 schema v2，无新增迁移。部署只更新插件产物，保留旧画布和 data.json，新增独立测试画布。不更改 Canvas 位置、尺寸、布局或 undo 历史。

仅处理活动 Canvas；框选、空间索引和原生编辑行为仍由 Obsidian 管理。保留 Phase 8 的完整包含判断与编辑保护；相同矩形和部分交叠分组不做自动标题避让。性能专项、主题兼容及整体收尾留到 Phase 10。

本阶段未增加阈值设置面板，默认使用表中阈值；可根据验收体验再调整。
