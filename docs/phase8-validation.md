# Phase 8 验证说明（0.0.7）

状态：Phase 1–8 已由用户在真实 Obsidian 中验收通过。本说明保留 Phase 8 范围；MAP 全局档见 Phase 9。

## 本阶段行为

普通节点仍使用四级属性，group 现在也真正按层级显示：

| 档位 | 普通节点 | group |
| --- | --- | --- |
| DETAIL | L1–L4 完整显示 | 全部显示原生边缘标题 |
| STRUCTURE | L1–L3 简短标签，L4 隐藏 | L1/L2 边缘标题，L3 可用中央标题，L4 隐藏 |
| OVERVIEW | L1/L2 简短标签，L3/L4 隐藏 | L1 边缘标题，L2 可用中央标题，L3/L4 隐藏 |

“可用中央标题”还要经过嵌套协调：内部存在同等或更高优先级的可见对象，或者正在编辑的对象时，该 group 保留边缘标题。默认同为 L2 的嵌套 group，只在最内层可概括区域使用中央标题。

**组内 L1/L2 普通节点现在会保留。** 此前“一进 OVERVIEW 就隐藏所有组内普通节点”的规则已移除。如果希望该区域只显示中央标题，把内部普通内容保留为默认 L3 即可。

隐藏 group 自身不等于隐藏其全部内部对象；重要子节点、重要子 group 仍按自身规则保留。连线按最终端点显隐同步隐藏线条、箭头和标签。

## 在 Obsidian 中验收

1. 关闭再启用 **Semantic Map Canvas**，加载 0.0.7。
2. 打开 **Semantic Map Canvas - Phase 8.canvas**。全部 group 默认 L2，普通节点默认 L3，无需预设层级。
3. 缩小至 23% 以下进入 OVERVIEW：最外层 group 保留边缘标题；“研究与灵感”显示中央标题；“项目”保留边缘标题，“项目子主题”显示中央标题；普通正文隐藏。
4. 放大后，把最外层 group 改为 L1，再缩回 OVERVIEW：外层仍是边缘标题，内层效果保持。
5. 把“研究与灵感”中的普通节点改为 L1 或 L2：OVERVIEW 中此节点显示简短标签，该 group 改为边缘标题，避免中央标题覆盖重点内容。恢复 L3 后，该节点隐藏，group 中央标题恢复。
6. 把“项目”group 设为 L4：“项目”边框、背景和标题隐藏，但 L2 的“项目子主题”仍显示。再恢复“项目”为 L2。
7. 把“项目子主题”设为 L3，里面的普通节点设为 L4：STRUCTURE 中该 group 显示中央标题；OVERVIEW 中该 group 隐藏，其外层“项目”显示中央标题。恢复它们为 L2/L3 后回到原效果。
8. 检查连接 group 的连线：任一端点 group 隐藏时，线、箭头和标签一起隐藏；放大后恢复。
9. 在 DETAIL 中拖动内层 group，使其部分移出外层边界，再缩小：不再算完全包含；使用原生 undo 恢复后，再次缩小，嵌套标题关系应恢复。插件不改坐标和尺寸。
10. 检查普通节点和 group 名称编辑。编辑中的低优先级对象应保留，包含它的可见祖先不显示中央标题遮挡；结束编辑后恢复当前规则。编辑保护沿用约 300ms 的扫描，快速操作可能短暂延迟。
11. 放大至 DETAIL、暂停显隐、切到普通笔记、切换 Canvas 或禁用插件：辅助标签与隐藏样式应清理，原生标题、内容和连线正常恢复。

初次分类仍为 25%/60%；切换边界仍为 23%/27%、58%/62%。没有新增 MAP 档，也没有更改层级默认值。

## 包含关系与边界

- 完整矩形包含才算内部；group 的相同矩形视为同级，不互为祖先。
- 保留所有真实包含关系，从内向外协调。共享的重要对象会保护所有包含它的分组，无需强行选一个直接父级。
- 部分交叠或矩形完全相同的分组不属于本阶段标题避让范围，仍可能发生标题相交；不做自动布局。
- 未识别类型的可见对象采取保守处理，不被 group 概括遮挡。
- 显隐改变的是渲染，不改变 Canvas 数据、原生选择集合、空间索引或 undo 历史；批量操作前仍可暂停显隐。
- 同档位按既有约 300ms 扫描重算包含关系，缩放补偿复用标签 DOM；大画布性能专项检查留在 Phase 10。
