# Semantic Map Canvas 0.0.12 — MIT license / MIT 许可证

## English

This release adopts the MIT license for Semantic Map Canvas starting with version 0.0.12. Plugin behavior is unchanged from 0.0.11.

- Copyright: 2026 ryanleefm.
- The upstream Obsidian sample plugin's original 0BSD notice is preserved in THIRD_PARTY_NOTICES.md.
- The distributed main.js includes both the MIT license and the upstream notice.
- The existing 0.0.11 tag and its original licensing are unchanged.

Desktop Obsidian 1.9.14+ is required. Download main.js, manifest.json, and styles.css from this release and place them in your vault's .obsidian/plugins/semantic-map-canvas/ folder. Restart Obsidian and enable Semantic Map Canvas. Existing data.json is preserved when replacing only these three files.

The interface remains English. [English guide](https://github.com/ryanleefm/semantic-map-canvas/blob/master/README.md) · [中文指南](https://github.com/ryanleefm/semantic-map-canvas/blob/master/README.zh-CN.md)

This is a pre-release. Very small titles require zooming in to read; large canvases may pause briefly during initial rendering. Mobile and broad theme/plugin compatibility have not been verified.
